# Покерный банкролл — десктоп-версия (Tauri)

Программа учёта покерных турниров в трёх валютах. Собирается в один
`.exe` весом около 8–12 МБ, работает без интернета и без установки
Python, Java или чего-либо ещё.

---

## Где хранится база

Файл **`poker_data.json`** лежит **рядом с `.exe`**.

Это значит, что программа портативная: скопировали папку на флешку или
в облако — вся история поехала вместе с ней. Точный путь всегда виден
внутри программы, в строке под панелью курса.

Рядом автоматически создаётся `poker_data.backup.json` — копия
предыдущего состояния. Если основной файл повредится, программа
поднимет данные из него сама.

Если папка окажется защищённой от записи (например, вы установите
программу в `Program Files`), база переедет в
`%APPDATA%\PokerTracker\poker_data.json`. Программа покажет этот путь.

Сохранение происходит сразу после каждого изменения, атомарно: сначала
во временный файл, потом подмена. Оборвать запись на середине нельзя.

## Как получить .exe, ничего не устанавливая

Сборка идёт на серверах GitHub — на вашем компьютере ничего
устанавливать не нужно.

1. Зарегистрируйтесь на **github.com** (бесплатно).
2. Нажмите **+** справа вверху → **New repository**.
   Имя любое, например `poker-tracker`. Можно оставить Private.
3. На странице пустого репозитория нажмите
   **uploading an existing file**.
4. Перетащите туда **всё содержимое этой папки** — вместе с папками
   `src`, `src-tauri` и `.github`. Нажмите **Commit changes**.
5. Откройте вкладку **Actions** сверху. Там уже будет идти сборка
   (жёлтая точка). Первый раз занимает 5–10 минут.
6. Когда появится зелёная галочка — откройте эту сборку и внизу, в
   разделе **Artifacts**, скачайте архив **PokerTracker-Windows**.
7. Внутри архива — установщик `.exe`. Запустите его, и программа
   появится в меню «Пуск».

Если вкладка Actions просит подтверждения — нажмите
**I understand my workflows, go ahead and enable them**.

## Как собрать у себя (если захочется)

Понадобятся Rust (rustup.rs) и Microsoft C++ Build Tools:

```
cargo install tauri-cli --version "^2" --locked
cargo tauri build
```

Готовый установщик появится в
`src-tauri/target/release/bundle/nsis/`.

---

## Обновление программы

Код интерфейса лежит целиком в `src/index.html`. Чтобы обновить
программу, замените этот файл и соберите заново — **база не
пострадает**, `poker_data.json` живёт отдельно.

Перед крупными изменениями всё же стоит нажать в программе
«Сохранить копию в файл».

---

## Что внутри

```
src/index.html        весь интерфейс и логика (один файл)
src-tauri/src/main.rs  чтение и запись базы на диск
src-tauri/tauri.conf.json  настройки окна и сборки
src-tauri/icons/       иконки приложения
.github/workflows/     автосборка на GitHub
```
